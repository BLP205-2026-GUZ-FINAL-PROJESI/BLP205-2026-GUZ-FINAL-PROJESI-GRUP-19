## Projenin Amaci

Bir kampus kutuphanesi icin kitap katalogunu, duyuru panosunu, odunc kitap bekleme sirasini,
islem gecmisini ve kampus birimleri arasindaki rota bilgilerini yoneten, menu tabanli bir
C++ konsol uygulamasi.
